## Hi, I'm EntityFX

I'm a software engineer interested in systems, performance and distributed software.

I work mostly with **.NET and Linux**, and I'm especially interested in understanding how software behaves across different layers — from distributed messaging and application architecture down to runtimes, compilers and CPU architectures.

I'm particularly interested in **Elbrus processors and the e2k architecture**, including their compiler model, performance characteristics and unusual architectural design.

My public projects are mostly engineering experiments, tools and long-running research projects rather than demo applications.

### Main interests

- .NET and Linux
- distributed systems and messaging
- MQTT and IoT
- performance engineering and benchmarking
- software architecture
- CPU architectures and low-level performance
- **Elbrus / e2k processors**
- runtimes and compiler optimizations
- emulation and computer architecture

### Selected projects

**MqttY** — a network topology simulator for prototyping distributed IoT systems, including routing, bandwidth constraints, failures, MQTT communication and simulation scenarios.

**MqttBenchmark** — tooling and experiments for load testing and comparing MQTT brokers under different workloads and configurations.

**Anybench** — a cross-platform CPU benchmark suite for studying processor, compiler and memory performance across different architectures.

**EntityFX-Bench** — a collection of equivalent benchmarks implemented across multiple programming languages for comparing runtimes and implementations.

**Besm6.Net** — a .NET implementation of the BESM-6 computer with Dubna OS support.

**MQS** — IoT telemetry generation and integration testing.

I enjoy projects that require going below the usual application abstraction layer — whether that means studying a protocol under load, measuring CPU behavior, comparing runtimes, exploring architectures such as **Elbrus/e2k**, or implementing a historical computer architecture.
